04로컬 실행

현재 로컬 설치된 MySQL 8.4.9(root @ localhost:3306, DB authdb)에 연결해 구동을 검증했습니다.

# 1) 의존성 설치 (venv 이미 생성됨)
pip install -r requirements.txt
pip install cryptography   # MySQL 8 caching_sha2_password 인증에 필요

# 2) 환경 변수 (.env — gitignore 됨)
DATABASE_URL=mysql+pymysql://root:****@localhost:3306/authdb
JWT_SECRET_KEY=<랜덤 값>

# 3) 서버 실행 (authdb 는 최초 1회 생성 필요)
uvicorn app.main:app --reload   # → http://localhost:8000/docs

# 테스트 (SQLite 사용, MySQL 불필요)
pytest

05UE5 연동

UE5 HttpModule 로 JSON 을 주고받습니다. 로그인 응답의 토큰을 저장한 뒤, 보호된 요청 헤더에 첨부합니다.

Req->SetURL(TEXT("http://localhost:8000/users/me"));
Req->SetVerb(TEXT("GET"));
Req->SetHeader(TEXT("Authorization"),
    FString::Printf(TEXT("Bearer %s"), *AccessToken));
!
남은 정리 항목
  • cryptography 를 requirements.txt 에 추가 (MySQL 8 사용 시 필요) — 현재 venv에만 설치됨
  • 스모크 테스트로 남은 test@example.com 계정 정리 여부 결정
  • 운영 배포 시 JWT_SECRET_KEY 는 안전한 랜덤 값 유지
